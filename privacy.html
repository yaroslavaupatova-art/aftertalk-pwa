Privacy notice

Pilot version · Effective 21 October 2026

Short version: Your profile and history stay in this browser. If you use the large microphone, the recording is sent through AfterTalk’s Supabase function to OpenAI for transcription. When you ask AfterTalk to create a next step, the resulting note, profile fields, and active context are sent through Supabase to OpenAI. If action generation is unavailable, the card is created on your device.

Information stored in your browser

AfterTalk stores your profile and writing preferences, active temporary context, saved context history, calendar preference, and prepared actions in local storage on the browser you are using. A prepared action can include the source note, next step, date, and follow-up draft.

There is no AfterTalk account or cross-device sync in this pilot. Clearing this site’s browser data removes these local records. They do not automatically transfer to another browser or device.

AI processing

Remote AI is used only when it has been configured and enabled by the pilot operator and you press Make my next step. AfterTalk sends the current note, the saved profile fields used to tailor the result, and the active temporary context to a Supabase Edge Function. The complete saved context history is not sent.

The function validates and limits the request, then sends its contents to OpenAI to generate a structured Action Card. The application does not intentionally write the note, profile, context, prompt, or generated card to the Supabase database. Supabase, OpenAI, and network providers may process request content and service metadata under the operator’s configuration and their applicable terms.

If AI is disabled, the note, profile, and context are handled by the deterministic rules engine in your browser and are not sent to Supabase or OpenAI for generation. If the AI service fails or times out, AfterTalk creates the card with that same on-device fallback.

Voice input

When you tap the large microphone and grant microphone permission, AfterTalk records a voice note in browser memory. Recording stops automatically after you finish speaking, can be stopped by tapping the button again, and is limited to 90 seconds. The audio file is sent to an AfterTalk Supabase Edge Function and then to OpenAI’s transcription service. The returned text is placed in the editable note field.

AfterTalk does not intentionally write the audio file or transcript to the Supabase database. The in-browser recording is discarded after the transcription request completes. Supabase, OpenAI, and network providers may process audio, transcript content, and service metadata under the operator’s configuration and their applicable terms. If direct recording is unsupported, you can use operating-system keyboard dictation or type instead.

Abuse prevention and service metadata

When the AI service is used, the Edge Function creates a salted SHA-256 fingerprint from the request IP address. The rate-limit table stores that fingerprint, a usage count, and the start of a one-hour usage window; it does not store the raw IP address in that table. Counters older than 48 hours are pruned when the rate-limit function next consumes a request.

The exact browser Origin check reduces casual cross-site abuse, but it is not authentication for non-browser clients and can be imitated outside a browser. Provider-side spending caps and usage limits are the final cost boundary.

This does not make use anonymous. Supabase and other network infrastructure can receive connection information, and OpenAI receives the content required to generate the card. The service also creates a request identifier and may record limited operational information such as provider response status, model, and token usage.

Calendar handoff

  • Google Calendar: AfterTalk opens a prefilled page on Google Calendar containing the action details, source note, and draft. You review it and click Save; AfterTalk does not save the event for you. Google uses your account’s normal notification settings.
  • Apple Calendar: AfterTalk creates an `.ics` calendar file on your device containing the action details, source note, draft, and a 30-minute reminder. You open the file and confirm whether to add it. AfterTalk does not write directly to Apple Calendar.

What not to enter

Do not enter passwords, payment information, highly sensitive personal data, or confidential information you are not authorized to process. Capture your own post-conversation notes rather than recording other people without permission.

Changes

This notice may change if AfterTalk adds accounts, cloud storage, new AI providers, analytics, or integrations. The effective date will be updated when the data practices change.
